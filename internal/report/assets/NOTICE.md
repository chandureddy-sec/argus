# Bundled map data

`world_land.path` is SVG path data (equirectangular, 1000×500) generated from
`land-110m.json` in [world-atlas](https://github.com/topojson/world-atlas)
v2.0.2 (ISC License, Copyright 2013-2019 Michael Bostock), which is derived from
[Natural Earth](https://www.naturalearthdata.com/) 1:110m land data (public
domain).
